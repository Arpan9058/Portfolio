Personal project · Web application

Prepto

What it is: a practice tool for people preparing for job interviews.

What it does: you upload your CV and a job advert, and it scores how well the two match and tells you which skills are missing. You can then run a practice interview — technical or general — write and run code in the browser for the coding rounds, and get a PDF report at the end. A progress page tracks how you improve over time.

  • CV-to-job-advert scoring, with the missing skills listed
  • Practice interviews with questions generated for the role
  • A code editor that actually runs the code you write
  • PDF reports and a progress dashboard
  • Node.js
  • Express
  • MongoDB
  • Firebase Auth
  • Gemini AI
  • Docker

Personal project · Stock & custody system

EKOTE

What it is: a system for tracking valuable equipment that gets signed in and out — built around an armoury, where every single item has to be accounted for.

What it does: each item gets its own QR code. Staff scan it to issue it to a named person or take it back in. The system refuses to issue the same item twice, keeps the stock count correct automatically, and keeps a full history of who had what and when, along with its maintenance record.

  • A QR code per item, scannable to look up its record
  • Sign-out and sign-in against a named person
  • Blocks double-issuing and keeps stock counts right
  • Full history and maintenance log per item
  • Java
  • Spring Boot
  • Spring Security
  • MySQL
  • QR codes
  • Docker
